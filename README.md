# AI Workplace Assistant

Build a modern, responsive web application called "AI Workplace Productivity Assistant" designed as a single integrated dashboard SaaS platform.

Structure & Layout:

1. Left Sidebar Navigation with tabs for:

   - Dashboard Overview

   - Smart Email Generator

   - Meeting Notes Summarizer

   - AI Task Planner

   - AI Research Assistant

   - AI Chatbot Interface

2. Main Content Area:

   - Header with current page title and user profile icon.

   - Distinct sections for Input and Output for each tool.

   - Editable AI outputs so users can refine results before copying or exporting.

   - Action buttons (Copy to Clipboard, Clear, Export).

3. Footer / Global Notice:

   - A visible "Responsible AI Disclaimer" stating: "AI outputs are generated to assist productivity and should be reviewed for accuracy before professional use."

Core Functional Features:

- Smart Email Generator: Dropdowns for Tone (Formal, Friendly, Persuasive) and Audience (Client, Manager, Team), input area for key bullet points, and an output window that displays a structured draft.

- Meeting Notes Summarizer: Input for raw transcripts, output cards showing Overview Summary, Action Items, Decisions, and Deadlines.

- AI Task Planner: Input for raw task lists, output providing a prioritized daily/weekly schedule with urgency tags.

- AI Research Assistant: Input for long articles or reports, output displaying key takeaways, structured insights, and practical recommendations.

- AI Chatbot Interface: Interactive chat window with real-time prompt-response flow for daily workplace queries.

Design Style: Clean, professional, minimal, corporate SaaS style with dark/light mode support.
